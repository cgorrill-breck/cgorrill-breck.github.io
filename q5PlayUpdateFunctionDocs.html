Q5Play Reference Guide

Unit: The Global Game Loop & No More Setup/Draw

1. Goodbye setup() and draw()!

In traditional p5.js, you divide your code into a setup() block (which runs once) and a draw() block (which loops). In Q5, this structure is completely flattened. Code placed directly in the script acts as your setup, and q5.update acts as your loop.

Concept How it works in Q5 Example
Initialization (The "Setup") Any code written at the top level of your file runs once when the script loads. This is where you create the canvas, set gravity, and spawn sprites. await Canvas(800, 600);
world.gravity.y = 10;
The Game Loop (The "Draw") Assign a function to q5.update. Q5Play will automatically run this block of code every single frame. q5.update = function() { ... };

2. Structuring Your q5.update Loop

Because Q5 handles physics and rendering automatically, you only need to put active logic inside q5.update. This keeps your game loop clean and focused on gameplay mechanics rather than drawing shapes.

What goes inside q5.update? Description
Backgrounds Clearing the screen every frame (e.g., background('#FDF5E6');).
Dynamic State Checks Checking if a player is grounded (e.g., player1.canJump = sensor.overlapping(walls) > 0;).
Collision Handlers Calling custom collision functions between dynamic groups (e.g., handleEnemyCollision(player, enemies);).
Input Handling Checking for continuous key presses for movement, if not handled internally by sprite logic.
Camera Updates Making the camera follow a specific target (e.g., camera.pos = player1.pos;).
💡 Logic Tip
Even though q5.update replaces draw(), you do not need to call drawSprites(). Q5Play automatically renders all sprites at the end of the update cycle!

3. Example Usage: Complete Q5 Structure

A Basic Q5 Platformer Script
// 1. "Setup" code goes right here at the top!
const TILE_SIZE = 16;
await Canvas(TILE_SIZE * 30, TILE_SIZE * 20);

// Configure physics and world variables
allSprites.pixelPerfect = true;
world.gravity.y = 10;

// Create your sprites and groups
let enemies = new Group();
let player1 = new Sprite(100, -80, TILE_SIZE * 0.8);
let camera = { zoom: 2, pos: { x: 0, y: 0 } }; // Example camera object

// 2. The Game Loop
q5.update = function () {
    // Clear the screen
    background('#FDF5E6');

    // Handle gameplay logic
    if (mouse.pressing()) {
        allSprites.debug = true;
    } else {
        allSprites.debug = false;
    }

    // Keep camera locked on the player
    camera.pos = player1.pos;
};
