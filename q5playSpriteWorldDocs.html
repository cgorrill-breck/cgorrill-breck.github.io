Q5Play Reference Guide

Unit: Sprites & World Basics

1. Canvas & World Dimensions

The canvas (or world) is your game screen. You can set its dimensions and access its size using built-in variables.

Task / Variable Syntax / Code Description
Set Canvas Size createCanvas(width, height); Creates the screen size in pixels. Usually goes inside setup().
Access / Set Width width Holds the width of the screen. You can read it (e.g., width / 2) or change it.
Access / Set Height height Holds the height of the screen. You can read it (e.g., height - 10) or change it.

2. Creating Sprites (Constructors)

A constructor creates a new sprite on the screen.

Constructor Type Syntax What it Creates
Default (No-Arg) let s = new Sprite(); Creates a default square sprite in the center of the screen (50x50 pixels).
Full Constructor (Rectangle) let s = new Sprite(x, y, w, h); Creates a rectangular sprite at position (x, y) with width w and height h.
Full Constructor (Circle) let s = new Sprite(x, y, d); Creates a circular sprite at position (x, y) with diameter d.

3. Position Coordinates (x, y, pos)

Sprites are positioned based on their center point.

Property Description Example Code
sprite.x The horizontal position on the screen. player.x = 200;
sprite.y The vertical position on the screen. player.y = 150;
sprite.pos / sprite.position Sets or accesses both X and Y coordinates at the same time using a vector. player.pos = {x: 100, y: 300};

4. Dimensions & Shape Behavior

Changing size properties dynamically affects both visual size and collider shape.

Property Shape Effect Example Code
sprite.w / sprite.width Sets horizontal width. Keeps or converts sprite into a box/rectangle. coin.w = 30;
sprite.h / sprite.height Sets vertical height. Keeps or converts sprite into a box/rectangle. coin.h = 30;
sprite.d / sprite.diameter Setting diameter automatically turns the sprite into a circle! ball.d = 40;
💡 Shape Tip
If you want a round sprite (like a ball or coin), set sprite.d or sprite.diameter instead of width and height!

5. Setting Colors

Property Description Example Code
sprite.color Sets the primary color of the sprite using color names or hex codes. player.color = 'red';
player.color = '#3b82f6';

6. Setting Images

Property / Method Description Example Code
sprite.img / sprite.image Assigns a loaded image object or file path directly to the sprite. player.img = 'hero.png';
Example Usage: Complete Setup
  await Canvas(800, 400);

  // Default sprite at center
  let box = new Sprite();

  // Custom player sprite
  let player = new Sprite(100, 200, 40, 40);
  player.color = 'blue';

  // Ball sprite using diameter
  let ball = new Sprite(400, 200, 50);
  ball.color = 'green';
  ball.diameter = 10;
  ball.x = jit(100); // jit is a random number  0 - 100
  ball.y = -height / 2; height is the canvas height. this is the top of the canvas
